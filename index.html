Metodologia

De onde vêm os dados

  • Expectativas: API de Expectativas de Mercado do Banco Central (Olinda), recurso ExpectativasMercadoAnuais, com a base de cálculo de 30 dias: são consideradas as projeções que cada instituição enviou nos últimos 30 dias, a mesma base do relatório publicado toda segunda-feira. Mediana, média, mínimo, máximo e número de respondentes vêm da API, sem nenhum ajuste.
  • Valor realizado: Sistema Gerenciador de Séries Temporais (SGS) do Banco Central, uma série por indicador (tabela abaixo).
  • Atualização: os dados são baixados de novo todo dia útil, às 09:17 (horário de Brasília).

Como cada ponto é calculado

  • Um ponto por semana: a API tem dados diários; usamos o último dia com dado em cada semana, em geral a sexta-feira, que é a data de referência do relatório da segunda seguinte.
  • Primeira projeção: a primeira semana em que aparece expectativa para aquele ano (o Focus pergunta sobre até quatro anos à frente).
  • Início do ano: a primeira semana do próprio ano de referência (a primeira com data a partir de 1º de janeiro).
  • Variação em 4 semanas: mediana atual menos a mediana de 28 dias antes.
  • Distância para o realizado: mediana menos o valor realizado. Positivo: o mercado esperava mais do que aconteceu; negativo, menos. Em pontos percentuais (p.p.) para IPCA, Selic e PIB, e em reais para o câmbio.
  • Quanto o mercado errou no início de cada ano: a mesma conta, usando a mediana da primeira semana de janeiro.

Por que a média de dezembro no câmbio

Os próprios dados mostram que a projeção de câmbio de fim de ano se comporta como a média de dezembro, e não como a cotação do último dia útil. Na última semana de cada ano, quando o resultado já está praticamente definido, a mediana do Focus fica, na média, muito mais perto da média de dezembro do que da PTAX do último dia útil (em negrito, a mais próxima em cada ano). Comparar com o último dia mostraria um erro que não é de previsão, e sim de definição.

Limites

  • O realizado só aparece para anos já encerrados.
  • O PIB é revisado pelo IBGE ao longo dos anos; comparamos com o valor mais recente, não com a primeira divulgação.
  • O número de instituições que respondem muda de semana para semana e aparece no detalhe de cada ponto.
