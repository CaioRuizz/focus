Como ler

  • Mediana é o valor do meio entre as projeções enviadas nos últimos 30 dias, a mesma base do relatório semanal.
  • Cada ponto é uma semana: usamos o último dado disponível de cada semana, em geral a sexta-feira que serve de referência para o relatório publicado na segunda.
  • IPCA é a inflação acumulada no ano; Selic é a meta no fim do ano; PIB é o crescimento real no ano; câmbio é a cotação do dólar no fim do ano.
  • Realizado vem do Sistema Gerenciador de Séries do Banco Central: IPCA em 12 meses em dezembro (série 13522), meta Selic em 31 de dezembro (série 432) e variação real do PIB no ano (série 7326, com as revisões do IBGE). Para o câmbio não mostramos o realizado, porque não há uma série equivalente à definição usada no Focus.

Fonte: Banco Central do Brasil, API de Expectativas de Mercado (Olinda) e SGS. Os dados são atualizados todo dia útil. Conteúdo informativo, não é recomendação de investimento.
